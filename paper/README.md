# Manuscript build notes

## Files

- `main.tex`: anonymous AAAI-27 main-track manuscript
- `supplement.tex`: separate technical supplement with full proofs
- `references.bib`: bibliography audited against primary metadata where noted
- `figures/`: generated by `../experiments/plot_results.py`
- `aaai2027-fallback.sty`: unofficial local preview only

## Venue-format build

```bash
bash ../scripts/fetch_aaai_author_kit.sh
bash ../scripts/build_paper.sh all
bash ../scripts/pdf_preflight.sh
```

The fetch script first tries the official AAAI author-kit file location and can
fall back to a pinned public mirror of the current kit when directory access is
blocked. The style and bibliography files must remain unmodified. They are
ignored by Git because venue files should be fetched afresh and never edited.

When `aaai2027.sty` is absent, the manuscript uses
`aaai2027-fallback.sty` for a close local preview. A fallback-built PDF is not a
venue-valid final submission.

## Current layout target

- pages 1--7: main content
- page 8: references only
- total: 8 pages, below the 9-page cap

Always recheck this after fetching the current kit. The automated preflight also
checks US-letter geometry, font embedding, Type 3 fonts, unresolved references,
overfull boxes, and identity strings.

## Anonymous artifacts

The public repository must not be linked from an anonymous submission. Run:

```bash
bash ../scripts/package_anonymous_artifact.sh
```

Then extract the resulting ZIP into a clean directory, install it, and rerun
`bash scripts/validate.sh` before upload.

## Reproducibility checklist

AAAI-27 requires the completed checklist as a separate upload. Build it with
`bash ../scripts/build_paper.sh checklist`; the output is `checklist.pdf`.
