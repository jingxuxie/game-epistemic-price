# AAAI-27 submission checklist

## Deadline eligibility

- [ ] The abstract was registered by July 21, 2026 at 11:59 PM UTC-12.
- [ ] Full paper uploaded by July 28, 2026 at 11:59 PM UTC-12.
- [ ] Technical supplement and anonymous code/data archive uploaded by July 31,
  2026 at 11:59 PM UTC-12.

A paper cannot enter the main track after the abstract-registration deadline.

## Manuscript format

- [ ] Build with the unmodified current `aaai2027.sty` and `aaai2027.bst`.
- [ ] Main content occupies pages 1--7 only.
- [ ] Total manuscript length is at most 9 pages.
- [ ] Pages after page 7 contain references only.
- [ ] Letter paper, embedded fonts, no Type 3 fonts.
- [ ] No `hyperref`, margin modification, font replacement, or manual style edit.
- [ ] Completed reproducibility checklist uploaded as the separate checklist PDF.

## Scientific audit

- [ ] Independent reader checks the 3-coloring reduction.
- [ ] Independent reader checks the projective-plane lower bound.
- [ ] Independent reader checks the two-sided cycle-dilation construction and
  inverse threshold.
- [ ] Every recent reference verified against a publisher/arXiv primary source.
- [ ] Novelty search repeated for zero-error coordination, hypergraph
  permissible-action partitions, and uncertain/robust metric center.
- [ ] Main-paper claims do not depend on the optional supplement.

## Anonymity

- [ ] No author names, affiliations, acknowledgments, repository URL, commit
  hashes, identifying file paths, or revealing PDF metadata.
- [ ] Anonymous artifact extracted into a clean directory and validated there.
- [ ] Public GitHub repository is not linked from the paper or supplement.

## Final upload inspection

- [ ] Download the uploaded PDF from OpenReview and visually inspect every page.
- [ ] Download and extract each uploaded supplementary archive.
- [ ] Confirm the abstract, title, author list, and keywords match registration.
- [ ] Confirm no accidental appendix is appended to the main PDF.
