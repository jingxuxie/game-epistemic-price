## Submission gates

1. Build and visually inspect using the unmodified current AAAI-27 kit.
2. Obtain an independent proof audit from a game-theory/information-theory
   reader.
3. Repeat the targeted novelty search and update `literature_audit.md`.
4. Upload only if an AAAI-27 abstract was registered before the deadline.

## Post-submission extensions

These are deliberately excluded from the seven-page main claim package:

- public/private randomization for positive-regret EPoC;
- two-way and interactive handshakes;
- many-agent compatibility complexes and coalition communication;
- approximate/learned private model embeddings with certified strategic cells;
- active information acquisition when the observed full-revelation frontier is
  flat;
- richer extensive-form or Dec-POMDP instantiations.
